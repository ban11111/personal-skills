# 生理结构、素材与左右约定

## 左右问题先找在哪一层

| 情况 | 正面未镜像时的正确关系 | 不要做 |
| --- | --- | --- |
| 角色右手 | 位于屏幕左侧 | 以屏幕位置命名后又按角色语义驱动 |
| 角色左手 | 位于屏幕右侧 | 为修一个动作全局互换所有节点名 |
| 角色转向或整体镜像 | 解剖身份仍属于该手，屏幕位置可变 | 再镜像一次手或道具抵消视觉错误 |
| 只修衣襟朝向 | 只调整衣服附件的镜像、原点与 offset | 镜像骨架、脸和全部握持关系 |

旧素材采用 screen-left/right 命名时，建立明确的 `screen → anatomical` 映射，不破坏已有 ID。新素材优先角色视角命名，并记录摄影机视角。三分之四或侧面角色还要记录 near/far limb，它们不是永久等同于左/右。

手型以拇指位置、手背/手掌、握拳方向和道具受力点一起判断。光看左右名字或者把图左右翻转，不能证明握持合理。

## 坐标、pivot 与父子关系

标准骨骼关系可从 root → pelvis → torso/head，pelvis → thigh → shin → foot，torso → upper_arm → forearm → hand 开始。裁切矩形中心通常不是关节。

用列向量时，附件的一种组合写法是：

```text
W_bone = W_parent × T(parent_local_joint) × R(local_angle)
W_art  = W_bone × R(calibration_angle) × S(uniform_scale) × T(-pivot_in_crop)
```

先明确自己的引擎采用哪种乘法顺序；不要把这个表达直接贴到行向量 API。图像 pixel 坐标、骨骼局部坐标和屏幕坐标只能通过明确变换连接。Pillow `Image.transform` 使用输出到输入的逆映射；反向映射工具不能直接接收前向矩阵。参见 [Pillow 官方说明](https://pillow.readthedocs.io/en/stable/reference/ImageTransform.html)。

源片长度 L_source、骨长 L_bone：等比缩放 s = L_bone / L_source，宽高同时乘 s。若因此接缝粗细不匹配，修剪/补绘邻接段并重新标定，不独立拉宽一个下臂掩盖问题。

## 关节接缝

- 标定近端中心、远端中心、两端可见宽度及接缝色；旋转围绕关节中心，而非袖口边缘。
- 上段末端与下段起点要有重叠余量，极值角仍不能露透明洞；必要时用匹配肤色/衣色的小型连接片。
- “盖一个大圆”只会把断层变成鼓包；先修宽度、中心和轮廓切线。
- 保留手腕与脚踝的自然收细。衣袖到皮肤、短裤到小腿是材质边界，不要整段填黑。
- 用标注图检查关节，再看无遮罩真实渲染。标记圆本身不能被当成真实关节表现。

## 腰胯是跨两个腿根的连续区域

腰带、骨盆、两侧大腿必须共同承担连接。把“小号裤头图片”放在两条独立腿上，会在走路和侧倾时露缝或像身体断成两截。

先按两侧髋 socket 与大腿近端宽度求覆盖范围；剪掉身体图里重复的臀部/裤腿轮廓。可采用带重叠的骨盆片、少量 mesh 变形或跟随两侧腿根的桥接轮廓。选择能保持原稿形状的最小方案，不为了省事把整个躯干压扁或拉长。腰部上边跟随躯干，下边随腿根运动，避免用固定矩形补丁硬遮。

## 2D 透视的能力边界

单一视角的平面分片不能凭空产生真实的转身、手掌翻面和背后体积。先判断动作所需视角是否仍在原图有效范围内；超出时准备对应视角/手型或少量 mesh 变形。不要只把上臂大角度旋转、手掌镜像或拉伸一遍，就声称完成了三维关节旋转。

手臂穿胸可能同时包含路径、前后层和素材朝向三种错误：分别修正。正确的 z-index 只能决定谁遮住谁，不能让不合理的姿势变得合理。

## 道具与握持

握持点是局部 anchor，不是图片中心。提公文包对准把手；托笔记本对准底座前沿/掌心；握杯对准手指包裹处。需要遮挡时拆出前手指、物体和后掌三个绘制层。

某些物体要保持大体水平或竖直：根据父骨世界旋转补偿，保留角色有意的倾倒/扇动动作。仅抵消前臂局部角度可能遗漏躯干旋转。公开模板不规定所有道具都必须锁世界方向。

Alpha 检查要区分“封闭实体内部”和“把手开孔”。在白、黑、棋盘格背景看公文包主体是否透明；不要把真正开孔也填上。不确定是 alpha、遮罩、裁切还是图层遮挡时，逐项关闭定位，不能直接刷一块背景色。

## 造型、服色与表情素材

保持角色间高矮、胖瘦、肩宽、姿态差异；“不要太胖”不等于所有人统一瘦身。年龄由用户设定与脸、发型共同表达，不能拿灰发老人代替“有资历的中年人”。

分组色使用明确上衣/袖子遮罩，保留明暗，排除皮肤、头发和道具。非分组部件共享中性贴图；真正需要区分的物件允许银、白、金属或棕灰等易读材质。衣服以外全部发黑曾让道具变成不可读黑团，因此颜色简化要服务识别。

表情层跟随头骨。眉毛、眼睛、嘴形应符合脸部透视，不用一个巨大的浮动表情覆盖原脸。戴眼镜角色镜片可透明，瞳孔与夸张眼形仍需可见。
