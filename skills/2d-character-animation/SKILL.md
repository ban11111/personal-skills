# 2D 人物骨骼动画

把“立绘能动”推进到“结构可信、动作连续、在真实场景中流畅”。先检查可观察的问题，再动对应层；不要靠加补间、降低人物尺寸或换工具掩盖错误。

## 使用方式

- 新角色或重做：先读 [前置约定](references/preflight.md)，再完成一个能覆盖持物和转身问题的代表角色。
- 左右、关节、腰胯、道具或遮挡异常：读 [结构与素材](references/anatomy-and-art.md)。
- 后退感、同手同脚、滑步、夸张反应：读 [运动与遮挡](references/motion-and-occlusion.md)。
- 切画面、闪烁、消失、快照打断或重播：读 [运行时与状态](references/runtime-and-state.md)。
- 卡顿、冷启动、缓存：读 [性能与资源](references/performance-and-cache.md)。
- 提交前读 [验收](references/acceptance.md)；不确定根因时查 [案例复盘](references/case-study.md)。
- 需要选择已有工具时读 [工具分工](references/tool-routing.md)，只加载当前环节相关的 skill。

## 核心约定

1. **角色左右与屏幕左右分开。** 正面未镜像时，屏幕左是角色右。骨骼语义、图像朝向、观看方向、运动方向、镜像次数分别记录；镜像不是重命名。
2. **先素材和关节，再动画。** 上下肢共用同一关节中心和匹配的接缝宽度；腰胯覆盖两侧腿根。不要把关节任意放在裁切矩形中心。
3. **骨骼树不等于绘制顺序。** 保留层级变换，同时让前臂、手指、道具和门框有独立可审查的前后关系；静止姿势对了不代表极值帧也对。
4. **位移与步态协同。** root 路径是真实移动，骨骼负责跨步；接触期脚在世界坐标中锁地，摆腿期抬脚。普通自然步态手臂与对侧腿配合；持物手可以约束幅度。
5. **肘膝的弯曲分支连续。** 角度符号依赖坐标系，不能照搬别人“正角/负角”。镜像后再核对屈曲方向，避免 IK 分支翻转和过伸。
6. **演员身份跨动作连续。** 从当前姿态混合到下一姿态，不先回静止；保留节点或稳定渲染实体。用视口坐标验证交接，不能只看局部 transform。
7. **喜剧通过表演成立。** 预备、主动作、停顿、余韵加上可读的眉眼嘴形；💢 是补充。角色差异来自轮廓、道具和反应，不靠随机乱抖。
8. **性能按满场测量。** 离线烘焙重复染色/切片，缓存静态素材；逐帧只更新改变的骨骼。测帧间隔、卡帧与输入响应，不只报告平均 FPS。
9. **恢复是显示当前状态。** 事件序号防重播，服务器不等待动画确认；后台/离开清理时钟和异步任务。流程最终姿态必须能直接重建。

这些约定不要求写实画风，也不覆盖用户明确要求的特殊步态、夸张变形或项目自己的无障碍策略。只改当前问题涉及的层，不顺手重画整个角色。

## 实施节奏

**最小样片**：保留现有正常比例，制作静止 → 完整行走 → 停步 → 互动/反应 → 最终停留；放进实际场景中回放。若用户要求先审核，在这个可审查结果处等审核，继续不依赖审核的工作，不把审核门槛推广到所有任务。

**扩大覆盖**：通过后推广到角色变体、不同服色和密集队列；再验证多人同时播放、冷资源、重复快照和中途退出。每次根据症状只修一个主要变量，避免同时改变美术、骨骼和节奏而失去因果线索。

**留下证据**：保存接缝/极值帧对照、1× 连续录屏、满场性能报告以及测量条件；明确实体设备尚未覆盖的部分。项目操作（合并、发布）沿用用户授权及仓库流程，本 skill 不授予额外发布权限。

## 可执行辅助检查

[结构契约示例](assets/rig-contract.example.json)和[轨迹示例](assets/motion-trace.example.json)仅为合成数据，需替换为项目导出的实测数据：

```bash
python scripts/audit.py rig assets/rig-contract.example.json
python scripts/audit.py trace assets/motion-trace.example.json
```

命令从本 skill 目录运行，也可使用脚本和数据的绝对路径。结构检查覆盖层级、左右元数据、裁切 pivot 和骨长匹配；轨迹检查覆盖锁脚漂移、异常缩放/透明度、节点更换、跳位、骨骼矩阵伸缩、弯曲约束及帧预算。具体数据契约与不能自动证明的部分见[验收文档](references/acceptance.md)。
